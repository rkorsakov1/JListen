# Poppins (self-hosted)

Latin and Latin-Extended `woff2` subsets of Poppins v24, taken from the Google Fonts
CDN (`fonts.gstatic.com`) so the site has no third-party font requests.

Weights: 400 (body), 600 (strong / buttons), 700 (heading).
